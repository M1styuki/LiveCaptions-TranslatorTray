# 使用说明

本交付仅支持 Windows 11 x64。实际验证结果及服务验证范围见 [验证范围](VALIDATION.md)。

## 启动和退出

软件只需要一个 `LiveCaptionsTray.exe`，支持 Windows 11 x64，无需安装 Rust、.NET 或编译工具。请将它放在自己有写入权限的文件夹中，与旧版程序分开放置。

双击后，软件驻留在右下角托盘。左击 CC 图标开启或关闭字幕；图标会随状态切换。右键菜单可以打开设置或退出程序。关闭主窗口会返回托盘；要完全退出，请使用托盘菜单的“退出”。

Windows 实时字幕需要已经完成系统自身的首次设置。若系统提示安装语音语言，请按 Windows 的提示处理。软件使用 Windows 的识别结果，再交给所选翻译服务。

## 选择翻译服务

在设置中选择翻译接口及目标语言，通过“API 设置”填写该服务需要的地址、模型或凭据。Google 接口不需要填写密钥；其他接口是否需要密钥或正在运行的本地服务，取决于所选服务。软件不会替你下载识别模型或启动新的模型服务。

主窗口保留“字幕”“设置”“历史记录”三个页面。侧栏底部依次是暂停或恢复翻译、开启或关闭字幕（CC）、置顶；字幕历史卡片按钮只在字幕页标题栏显示。将鼠标停在图标上可查看说明。CC 与托盘共用字幕启停状态：任一处开启都会启动识别和悬浮窗，任一处关闭或关闭悬浮窗都会停止本次字幕；暂停翻译仍保留识别。启动和停止期间按钮暂时不可点，失败后恢复关闭状态。托盘右键菜单保留 Windows 原生布局、字体和高亮，跟随系统深浅色主题。

设置页底部的“启动”分组提供“开机自启动”，默认关闭。开启后，当前用户登录 Windows 时自动启动托盘，不自动开启字幕识别。开关读取当前程序的 Windows 启动项，不写入翻译配置。移动 EXE 后请在新位置重新开启；如果在 Windows 启动应用中禁用了它，也需要在那里重新允许。

## 字幕浮窗

将鼠标移入浮窗可显示工具栏。“B”在普通与加粗之间切换，同时作用于原文和译文，启用时高亮。旧配置中的单行加粗状态会按双语加粗显示。

显示模式依次为双语、仅译文、仅原文。切换模式保留窗口大小、位置和工具栏位置，可在同一位置连续点击。窗口仍根据完整字幕内容自动调整高度；手动调整后不再自动收缩。

设置和 API 页随系统切换深浅色主题，采用统一的平整控件和中性深灰底色。“显示系统字幕”使用开关；关闭时，停止字幕浮窗也不会重新显示已隐藏的系统字幕窗口。

设置和 API 页使用不透明底色，文字渲染遵循 Windows ClearType 开关和 RGB/BGR 顺序。页面与控件淡化动画保留；字幕浮窗透明度独立设置。

“显示翻译耗时”在主窗口字幕页显示翻译任务从提交到完成的耗时，单位为毫秒；不包含此前的语音识别和分句等待，也不改变翻译速度。

## 历史记录与数据

历史页支持搜索、清除搜索、翻页、调整每页条数、刷新和导出。导出保存的是全部历史记录，而非当前页或当前筛选结果；文件为带 UTF-8 标记的 CSV，可由表格软件打开。“全部删除”需要确认，并会清除当前翻译上下文。

默认配置和历史保存在 EXE 旁的 `data` 文件夹。移动软件时，请在退出程序后一起移动该文件夹；只替换 EXE 可保留数据。配置可能含服务密钥，历史可能含字幕内容，请勿将整个 `data` 文件夹公开分享。

首次打开设置会直接显示设置页，并自动创建默认配置；在服务设置中填写所需参数即可。本版不提供旧配置导入，也不会自动搜索 EXE 旁的旧配置；已有 data 文件夹继续正常读取。若升级前已有未完成的数据迁移，恢复页仍可重试或指定原来源完成恢复，避免已有保留副本无法继续处理。

## 维护

本版按要求移除了关于页和检查更新功能。出现保存失败时，窗口会提示并提供重试；请先完成保存，再退出。软件可能在使用窗口或翻译时出现两个同名进程，这是按需启动的工作进程；引擎关闭且最后一个窗口关闭后，只保留托盘进程。
